# homebrew-tap

Official Homebrew tap for [Tokalang](https://github.com/tokalang) ecosystem developer tools.

## Included Formulae

| Formula | Description |
| :--- | :--- |
| **`trg`** | Fast, agent-friendly, symlink-safe code search & hydration CLI tool with native Model Context Protocol (MCP) server support. |

## Installation

You can install `trg` directly via:

```bash
brew install tokalang/tap/trg
```

Or tap this repository first:

```bash
brew tap tokalang/tap
brew install trg
```

## Updates

To update to the latest release:

```bash
brew update
brew upgrade trg
```

## Verification

Check the installed version:

```bash
trg --version
```
